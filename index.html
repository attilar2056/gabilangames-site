GUIA DE INSTALAÇÃO

Como instalar e usar no Software Elgato

Siga estas etapas para instalar sua integração no Windows.

  1. 1.
    Encerre o software original do dispositivo e também o Elgato Stream Deck antes de instalar.
  2. 2.
    Baixe o pacote de teste e extraia seu conteúdo. Localize os arquivos icuuc.dll e licence.key.
  3. 3.
    Abra a pasta de instalação do Elgato Stream Deck.
    O caminho padrão costuma ser:
    C:\Program Files\Elgato\StreamDeck
  4. 4.
    Coloque icuuc.dll e licence.key na pasta do Stream Deck. O Windows poderá solicitar permissão de administrador.
  5. 5.
    Inicie o Elgato Stream Deck e confira se seu dispositivo é reconhecido.
    A versão de avaliação funciona por 7 dias.

Caso não tenha encontrado a pasta do Stream Deck

Clique com o botão direito no atalho do Elgato Stream Deck e escolha “Abrir local do arquivo”. Caso seja aberta apenas uma pasta de atalhos, repita a ação no atalho encontrado.
